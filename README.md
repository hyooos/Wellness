# WELL-FLOW

### 웰니스 관광지역 성과 진단 대시보드

추천 웰니스 관광지가 있는 지역의 관광 흐름을 **탐색·방문·숙박·체류·소비**
다섯 지표로 분석합니다. 무주·완도·순창·완주의 신규 선정 전후 변화를 같은 기준으로
비교했습니다.

**[대시보드 바로 보기 →](https://well-flow-dashboard.vercel.app/)**

[최종 보고서 PDF](<2026 한국관광 데이터랩 활용 경진대회 제출용 연구보고서.pdf>) ·
[분석 설계](PROJECT.md) ·
[숙박 공급 분석 방법](docs/숙박_공급_반영방법.md)

## 무엇을 분석했나요?

| 지표 | 확인하는 내용 | 데이터 |
|---|---|---|
| **탐색** | 숙박 목적지에 대한 관심 | 티맵 숙박검색 |
| **방문** | 지역을 찾은 외지인 규모 | KT 이동통신 |
| **숙박** | 방문자 중 숙박한 비율 | KT 이동통신 |
| **체류** | 지역에 머문 시간 | KT 이동통신 |
| **소비** | 지역에서 발생한 관광소비 | 신한카드 |

다섯 지표는 순서대로 이어지는 전환 단계가 아니라 **각기 다른 관광성과를 관측하는
독립 지표**입니다.

## 지정 1년차 변화

아래 수치는 지정 직전 1년(P2)과 지정 1년차(P3)를 비교한 결과입니다.

![네 지역의 지정 직전 대비 지정 1년차 변화](docs/images/designation-year-change.png)

| 지역 | 한눈에 보는 결과 | 우선 확인할 부분 |
|---|---|---|
| **무주** | 탐색·방문·숙박·소비 상승 | 체류 정체와 코로나19 회복기 영향 |
| **완도** | 방문은 유지, 탐색·숙박·소비 하락 | 관심과 숙박 수요의 약화 여부 |
| **순창** | 탐색 상승, 소비 하락 폭이 가장 큼 | 소비 업종과 지출 구조 |
| **완주** | 방문·소비 유지, 숙박·체류 하락 | 숙박과 장기 체류 여건 |

## 분석 대상과 기간

| 지역 | 관광지 | 신규 선정 발표 | 분석 기간 |
|---|---|---:|---|
| 전북 무주군 | 태권도원 상징지구 | 2022-04-19 | 2020.04–2024.03 |
| 전남 완도군 | 완도 해양치유센터 | 2024-04-24 | 2022.04–2026.03 |
| 전북 순창군 | 쉴랜드 | 2024-04-24 | 2022.04–2026.03 |
| 전북 완주군 | 아원고택 | 2024-04-24 | 2022.04–2026.03 |

각 지역의 발표월을 기준으로 지정 2년 전(P1), 지정 직전(P2), 지정 1년차(P3),
지정 2년차(P4)를 각각 12개월로 구성했습니다.

> **해석 범위**
>
> 분석 결과는 관광지 자체의 방문객이나 매출이 아니라 **시설 소재 시군구 전체의
> 관광 흐름**입니다. 지정 시점 분석은 구조변화를 탐색하는 방법이며, 비교 지역이 없어
> 지정의 인과효과로 단정하지 않습니다.
